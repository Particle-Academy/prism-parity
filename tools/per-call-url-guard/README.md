The per-call-url-guard corpus asks whether a provider url passed for ONE call is refused, before any request, when it names a loopback, private, link-local, shared, unique-local, unspecified or cloud metadata address. Every observation is native execution output, entered through each language's `Prism.text().using(...)`. `agrees` is derived from all three columns.

Run `node tools/per-call-url-guard.mjs php --check`, then repeat with `ts` and `py`. `--record` explicitly rewrites one native column. `PRISM_PHP_SRC` points the PHP adapter at a prism checkout: the reference's classes and its `config/prism.php` are loaded from there ahead of the runner's locked vendor, which is how CI reads the default branch. Without it, the installed reference in `runners/php/vendor` is used; `PRISM_AUTOLOAD` replaces that autoloader. `PRISM_TS_DIST`, `PRISM_PY_SRC`, `PRISM_PHP_BINARY` and `PRISM_PY_BINARY` work as in credential-scope. `PER_CALL_URL_GUARD_CASES` reads a different copy of the corpus, for a negative control against unchanged code.

An observation is `dispatched` and `refusal` (`private_address_refused`, `scheme_not_allowed` or null) and nothing else. The message is outside the contract and never recorded; `contract.mjs` refuses any other field. Environment names are fixed in `environment-names.json` and isolated per row. PHP uses Laravel's HTTP fake with stray requests prevented, TypeScript captures `fetch`, and Python captures the default transport and refuses DNS and sockets. Every fixture answers 500.
